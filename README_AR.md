# SEGA IPTV Player — مشروع Android IPTV Player + لوحة تحكم

**الإصدار:** نموذج أولي مزدوج (MVP 0.2)، وليس APK نهائيًا منشورًا.

هذا المشروع يحتوي على تطبيق أندرويد أصلي بـ Kotlin / Jetpack Compose ولوحة تحكم عربية مبنية بـ FastAPI وSQLite. يحتوي على واجهتين منفصلتين: واجهة الهاتف باللمس وواجهة Android TV / Google TV باستخدام أزرار الريموت. يستعمل Android Media3 ExoPlayer لتشغيل مصادر الفيديو المصرح باستخدامها.

## ما تم تنفيذه

- مشغّل M3U / M3U8، واستيراد M3U محلي من الهاتف، وعرض القنوات والتصنيفات والشعارات والبحث والمفضّلة.
- شاشة تفعيل تُظهر **Virtual MAC** و**Device Key** مع نسخ البيانات.
- واجهة تلفزيون منفصلة بنمط **10-foot UI**: قوائم جانبية كبيرة، بطاقات قنوات، تصنيفات، تحديد واضح للعنصر النشط (Focus Ring) والتنقل بواسطة الأسهم وOK والرجوع.
- واجهة هاتف تعمل باللمس بالشريط العلوي والأقسام؛ يختار التطبيق واجهته تلقائياً حسب نوع الجهاز.
- ظهور التطبيق في **Android TV Launcher** بفضل `LEANBACK_LAUNCHER` وشعار تلفزيون 320×180 ودعم الأجهزة غير اللمسية.
- مشغّل فيديو بعرض كامل على التلفزيون ومشغّل مضمن على الهاتف، مع ExoPlayer وتحكم أساسي بالريموت.
- تسجيل الجهاز تلقائيًا في لوحة التحكم، ثم تفعيل الجهاز أو إيقافه وتحديد تاريخ انتهاء التفعيل.
- إضافة وتعديل وحذف قوائم M3U. يمكن إتاحتها **لجميع الأجهزة** أو تخصيصها **لأجهزة محددة**.
- تغيير اسم التطبيق داخل الواجهة، لون الواجهة، رابط الخلفية ورابط الشعار دون إعادة نشر APK.
- تزامن يدوي عند الضغط على زر التحديث، وتزامن آلي كل خمس دقائق أثناء تشغيل التطبيق.
- حماية لوحة التحكم باسم مستخدم وكلمة مرور، وتخزين **بصمة تجزئة** مفتاح الجهاز بدلاً من حفظه كنص صريح.
- اختبارات خلفية تتحقق من التسجيل والتفعيل وإضافة القوائم وإيقاف الجهاز.

**ليس متضمّنًا في هذا الإصدار:** ملف APK مبني، EPG، أفلام ومسلسلات VOD، Xtream Codes، Stalker/Ministra MAC portals، نظام دفع، موازنة أحمال، تشغيل DRM أو نظام حماية اشتراكات تجاري ضد العبث. يلزم اختبار التنقل الكامل على أجهزة Android TV حقيقية قبل الإطلاق. ليس هناك أي قنوات تجارية أو محتوى مضمن.

## 1 — تشغيل لوحة التحكم على حاسوبك

المتطلبات: Python 3.10+ (يوصى 3.12)، إنترنت لتثبيت المكتبات.

```bash
cd panel
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate
pip install -r requirements.txt
```

**Windows (PowerShell):**

```powershell
$env:ADMIN_USERNAME="admin"
$env:ADMIN_PASSWORD="اختر_كلمة_مرور_طويلة_جدا"
python -m uvicorn main:app --host 0.0.0.0 --port 8000
```

**macOS/Linux:**

```bash
export ADMIN_USERNAME='admin'
export ADMIN_PASSWORD='اختر_كلمة_مرور_طويلة_جدا'
python -m uvicorn main:app --host 0.0.0.0 --port 8000
```

ثم افتح في المتصفح: **http://127.0.0.1:8000/admin**. تظهر نافذة دخول باسم مستخدم وكلمة مرور. إذا كانت كلمة المرور غير محددة، ستُرفض جميع محاولات الدخول عمدًا.

### تشغيل Docker

```bash
cd panel
cp .env.example .env
# عدّل ADMIN_PASSWORD داخل .env إلى كلمة قوية
# لا تعرض المنفذ مباشرة إلى الإنترنت؛ استعمل HTTPS reverse proxy
docker compose up --build -d
```

## 2 — إعداد تطبيق Android Studio

1. افتح مجلد `android/` في أحدث إصدار مناسب من Android Studio (Open Project).
2. ثبّت Android SDK 36 وJDK 17 واترك Gradle يتزامن مع الإنترنت.
3. إصدار Gradle المطلوب: **8.13**. أضفنا `gradlew` و`gradlew.bat` لجلب **Gradle wrapper JAR الرسمي** والتحقق من SHA-256 في أول تشغيل. يحتاج الإنترنت لأول تشغيل.
4. شغّل محاكي هاتف **أو جهاز Android TV Emulator** من Device Manager. على التلفزيون جرّب الأسهم ↑ ↓ ← → وزر OK وBack. الإعداد الافتراضي يستعمل `http://10.0.2.2:8000` للوصول إلى الخادم الموجود على نفس الحاسوب.
5. اضغط **Run** لتجربة التطبيق على المحاكي، أو استخدم **Build > Build APK(s)** لإنتاج APK تجريبي **واحد للهاتف والتلفزيون**.
6. شغّل التطبيق مرة واحدة حتى يسجّل الجهاز ويعرض Virtual MAC وDevice Key.
7. افتح لوحة التحكم، ثم **الأجهزة والتفعيل**، اختر الجهاز وفعّله.
8. انتقل إلى **قوائم M3U** وأضف رابط قائمة مصرّح باستعمالها واختر توزيعها، ثم اضغط «التحقق من التفعيل» في التطبيق.

### هاتف Android حقيقي

**هام:** عنوان `10.0.2.2` صالح للمحاكي فقط. على هاتف متصل بنفس شبكة الحاسوب استعمل عنوان IPv4 للحاسوب في الشبكة (مثل `http://192.168.1.50:8000`)، أو عنوان خادم HTTPS عام موثوق.

يمكن تغيير العنوان من `android/gradle.properties` بإضافة السطر:

```properties
SEGA_IPTV_BACKEND_URL=http://192.168.1.50:8000
```

أو عبر أمر Gradle:

```bash
./gradlew :app:assembleDebug -PSEGA_IPTV_BACKEND_URL=https://your-domain.example
```

غيّر عنوان الخلفية إلى عنوان HTTPS عام حتى تصل الصورة إلى الأجهزة خارج الشبكة. إعداد رابط الخادم داخل التطبيق حاليًا يتم وقت البناء؛ بقية عناصر الهوية والقوائم تُحدّث من اللوحة دون إعادة بناء التطبيق.

### التوزيع

- ملف الـAPK الناتج محليًا غالبًا في `android/app/build/outputs/apk/debug/app-debug.apk`.
- للتوزيع الرسمي، اعمل `signing config` خاصًا بك ووقّع إصدار release وفكّر في Google Play requirements وسياسة الخصوصية وتراخيص البث.

## 4 — شرح MAC وDevice Key

من Android 10، التطبيق العادي لا يستطيع الاعتماد على عنوان MAC الحقيقي الثابت للجهاز. لهذا المشروع يولّد **عنوان MAC افتراضيًا** ثابتًا بالنسبة لتثبيت التطبيق، وليس MAC الخاص بشبكة Wi‑Fi، ويربطه بمفتاح طويل خاص بالتثبيت (Device Key). يمكن نسخ الاثنين من شاشة التفعيل وإدارة الجهاز من لوحة التحكم. عند حذف التطبيق أو حذف بياناته قد تتغير هذه المعرفات؛ إعادة التثبيت ستظهر كجهاز جديد.

هذا النظام **تعريف وتفعيل أساسي** وليس نظام ترخيص تجاريًا مضادًا للاستنساخ. للإنتاج ينصح باستخدام Android Keystore وPlay Integrity وإدارة جلسات الأجهزة وسجلات الإدارة ومحددات طلبات API.

## 5 — ما يجب تحسينه قبل الإطلاق التجاري

1. استخدام **HTTPS حصريًا** للخادم وروابط المحتوى حيثما أمكن، وإزالة `android:usesCleartextTraffic="true"` بعد انتهاء التطوير.
2. إضافة مصادقة جلسات إدارية قوية، CSRF protection، rate limiting، وكشف إساءة الاستخدام. حماية HTTP Basic المعتمدة هنا مناسبة للعرض والتجربة **مع HTTPS**، وليست إدارة مستخدمين متكاملة.
3. تشفير أسرار الأجهزة في Android Keystore وتوثيق أصل التطبيق عبر Play Integrity.
4. تأمين قاعدة بيانات SQLite ونسخها احتياطيًا؛ لا تنشر ملفها أو تعرض `/admin` بدون TLS.
5. معالجة الروابط المتضمنة بيانات دخول باعتبارها **أسرارًا**؛ بيانات القوائم محفوظة في قاعدة SQLite وغير مشفرة على مستوى الملف.
6. دعم EPG XMLTV والتصنيف Live/VOD/Series وملفات M3U الكبيرة، واختبار وتجويد كافة سيناريوهات التنقل بالريموت على أجهزة Android TV مختلفة.
7. مراجعة سياسة المحتوى: التطبيق **مشغل فقط**، وليس وسيلة للوصول غير المصرح به للمحتوى المدفوع؛ استخدم مصادر وقنوات لديك حقوقها.

## تجربة الهاتف والتلفزيون

- **الهاتف:** افتح التطبيق؛ ستظهر الواجهة اللمسية الأصلية.
- **Android TV / Google TV:** افتح التطبيق من قسم Apps، وستظهر قائمة جانبية وبطاقات كبيرة. الأسهم للتنقل، OK للتشغيل أو اختيار عنصر، Back للعودة إلى الرئيسية أو الخروج من المشغّل.
- **لوحة التحكم:** نفس الخادم يدير أجهزة الهاتف والتلفاز عبر MAC افتراضي وDevice Key مستقلين لكل تثبيت.
- **ملاحظة:** Android TV وGoogle TV مدعومان من حيث بنية التطبيق، لكن بعض أجهزة TV Box غير المعتمدة قد لا تعرّف نفسها كتلفزيون؛ حينها تظهر واجهة الهاتف العريضة. من الممكن لاحقاً إضافة مفتاح اختيار الواجهة يدوياً.
- **MAC:** هذا المعرّف افتراضي **للتسجيل والترخيص فقط**. لا يوجد ربط ببوابات Stalker/Ministra، ولا تسجيل دخول MAC Portal في هذه النسخة.

**ملاحظة التحقق:** نجحت اختبارات Backend محلياً. لم يتوفر Android SDK هنا، ولذلك **لم ننتج ملف APK ولم نتمكن من إجراء Android build أو اختبار الريموت على محاكي/جهاز حقيقي**. يلزم فتح المشروع في Android Studio للتجميع والتجربة قبل توزيعه.
